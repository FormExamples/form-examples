# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Test-type selection (BSACI / EAACI)

| Test type | First-line for | Notes |
| --- | --- | --- |
| Skin-prick test | IgE-mediated food, aeroallergen, venom, latex | Invalidated by antihistamines |
| Intradermal test | Drug and venom (when skin-prick negative) | Higher sensitivity, systemic-reaction risk |
| Patch test | Delayed contact dermatitis | Read at 48 / 72–96 h |
| Specific-IgE blood | When skin testing unsafe or invalid | Unaffected by antihistamines |
| Drug-provocation challenge | Confirm / exclude drug allergy | Supervised, resuscitation-ready |

## Appropriateness (BSACI / EAACI indication match)

Ordinal 1–9 scale in three bands: usually-appropriate (7–9),
may-be-appropriate (4–6), usually-not-appropriate (1–3). Mapped per
(indication × test type). Testing without a clear clinical history of a specific
reaction (indiscriminate panel testing) scores low.

## Validity and safety axis

| Band | Triggers |
| --- | --- |
| Contraindicated | On antihistamines + skin-prick / intradermal requested (test invalid); active skin disease at site |
| Caution | Beta-blocker + anaphylaxis history (impaired adrenaline response); previous anaphylaxis (resuscitation readiness) |
| Ok | None of the above |

**Antihistamines** suppress the weal-and-flare response and must be withheld for
an appropriate washout (typically five half-lives of the agent) before skin
testing; otherwise the result is a false negative. **Specific-IgE blood testing**
is the recommended redirect when antihistamines cannot be stopped or skin
disease is active.

## Triage tiers

| Tier | Target | Triggers |
| --- | --- | --- |
| Urgent | ~2 weeks | Recent anaphylaxis investigation, perioperative / drug allergy blocking treatment, venom allergy in high-exposure occupation |
| Routine | standard booking | Rhinitis / asthma aeroallergen work-up, chronic urticaria, stable food allergy |
