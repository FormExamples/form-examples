# PACU Record — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
Post-Anaesthesia Care Unit (PACU) recovery wizard with the Modified Aldrete
discharge-readiness scorer; `dashboard.html` is the recovery-team dashboard.
Shared `css/` and `js/` (the PACU scoring engine in
`js/{types,rules,grader,flags}.js`, the apps in `js/form-app.js` +
`js/dashboard-app.js`).
