# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Appropriateness (ACR Appropriateness Criteria / RCR iRefer)

Ordinal 1–9 scale in three bands: usually-appropriate (7–9),
may-be-appropriate (4–6), usually-not-appropriate (1–3). Mapped per
(indication × scan type). FDG-PET-CT is usually appropriate for staging /
restaging of many solid tumours and lymphoma, treatment-response assessment,
and suspected recurrence; PSMA-PET for prostate cancer; DOTATATE-PET for
neuroendocrine tumours; amyloid-PET for selected dementia work-up; cardiac-PET
for myocardial viability and cardiac sarcoid.

## FDG patient preparation and glucose control (EANM / SNMMI)

| Parameter | Target |
| --- | --- |
| Fasting | ≥ 4–6 hours; water permitted; stop tube feeds |
| Blood glucose (EANM) | below ~7 mmol/L preferred |
| Blood glucose (SNMMI) | 7–11 mmol/L acceptable |
| Action threshold | recheck / reschedule if above ~11 mmol/L |
| Diabetes | measure and document glucose before tracer; hyperglycaemia is not an absolute contraindication |

Uncontrolled glucose causes competitive inhibition of FDG uptake and raised
muscle background, degrading image quality, so the engine flags it and pushes
the preparation-safety band to caution / contraindicated.

## Radiation justification (IR(ME)R)

Every exposure must be justified: the benefit must outweigh the detriment. The
referrer supplies the clinical justification statement; the practitioner /
operator justifies and optimises. Pregnancy is a key consideration — an FDG-PET
study in a pregnant patient requires explicit justification and is otherwise a
relative contraindication.

## Triage tiers

| Tier | Target | Triggers |
| --- | --- | --- |
| Emergency | same day | unstable acute oncological / infective emergency needing immediate staging |
| Urgent | 1–7 days | suspected aggressive malignancy, treatment-decision-blocking restaging, MDT deadline |
| Routine | standard booking | elective staging, surveillance, response assessment |
