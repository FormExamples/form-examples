# First Aid Training Checklist — consolidated front-end (SvelteKit)

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4. Vitest for unit tests.

Single consolidated front-end: examiner checklist wizard plus the training
coordinator SVAR DataGrid dashboard, on RESTful routes
(`/first-aid-training-checklists/` list + `/first-aid-training-checklists/[id]` wizard).

See parent [`../index.md`](../index.md) for the form specification.
