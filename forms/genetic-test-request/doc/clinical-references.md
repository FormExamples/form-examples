# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Appropriateness — NHS National Genomic Test Directory

The National Genomic Test Directory identifies the most appropriate test for each
clinical indication and the testing methodology by which it should be delivered.
A supplementary eligibility-criteria document sets out which patients should be
considered for testing under each clinical indication (CI), each with a CI ID
beginning with `R`, and the requesting specialties. All referrals are triaged by
the local Genomic Laboratory Hub, which selects the most appropriate constituent
test(s) for the request.

There is **no single published 1–9 numerical genetic-ordering score**. This form
anchors the 1–9 appropriateness axis on Test Directory eligibility:

| Score | Band | Meaning |
| --- | --- | --- |
| 7–9 | usually-appropriate | Indication and patient clearly meet a Test Directory CI |
| 4–6 | may-be-appropriate | Partial / borderline eligibility; missing supporting criteria |
| 1–3 | usually-not-appropriate | No matching eligible Test Directory indication |

## Consent & counselling — ACGS / mainstreaming guidance

Informed consent (a Record of Discussion) is recommended prior to all genomic
testing and is **required** prior to predictive / presymptomatic testing.
Pre-test genetic counselling supports informed decision-making and is mandatory
for predictive testing, where a 50 % genetic risk may turn to certainty.

| Band | Meaning |
| --- | --- |
| ok | Consent obtained and (where required) counselling offered |
| caution | Consent or counselling incomplete but not mandatory-blocking |
| not-met | Predictive / presymptomatic request with consent or counselling absent (blocking) |

## Triage tiers

| Tier | Target | Triggers |
| --- | --- | --- |
| Urgent | time-critical | prenatal diagnosis, acutely unwell proband, time-limited management decision |
| Routine | standard turnaround | diagnostic, carrier, predictive, pharmacogenomic in stable patients |

Prenatal test requests are always time-critical.
