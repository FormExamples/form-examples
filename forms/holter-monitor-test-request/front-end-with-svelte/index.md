# Holter Monitor Test Request — front-end with Svelte

SvelteKit single continuous single-page wizard for capturing an ambulatory ECG
(Holter) monitoring request and presenting the four-axis vetting grade
(appropriateness, urgency / triage, request completeness, clinical priority)
plus the overall vetting recommendation. A vetting dashboard at
`/holter-monitor-test-requests` lists sample requests with their computed grades.
