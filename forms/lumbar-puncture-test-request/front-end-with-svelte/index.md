# Lumbar Puncture Test Request — front-end with Svelte

SvelteKit single-page wizard for capturing a lumbar puncture (LP) request /
referral and presenting the four-axis vetting grade (appropriateness, safety /
contraindication, request completeness, triage priority) plus the overall
vetting recommendation. RESTful routes: a vetting dashboard at
`/lumbar-puncture-test-requests` lists sample requests, and the wizard at
`/lumbar-puncture-test-requests/[id]` edits one request.
