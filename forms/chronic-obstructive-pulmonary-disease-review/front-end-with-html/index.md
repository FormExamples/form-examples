# COPD Review — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
COPD annual-review wizard; `dashboard.html` is the clinician dashboard. Shared
`css/` and `js/` (the GOLD / ABE / completeness grading engine in
`js/{types,rules,grader,flags}.js`, the apps in `js/form-app.js` +
`js/dashboard-app.js`).
