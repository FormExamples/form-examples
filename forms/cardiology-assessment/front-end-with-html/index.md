# Cardiology Assessment — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
assessment wizard; `dashboard.html` is the clinician dashboard. Shared `css/`
and `js/` (the CCS / NYHA scoring engine in `js/{types,rules,flags,grader}.js`,
the apps in `js/form-app.js` + `js/dashboard-app.js`).
