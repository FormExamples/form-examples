# UK LPA for Financial Decisions — Full Stack with Rust Axum Loco Tera

Server-rendered Rust web app for the UK Lasting Power of Attorney for
Property and Financial Affairs (LP1F) deed. Implements the 15-step
single-page wizard plus the validation engine that fires statutory
blocker rules and additional flags before the LPA is signed and sent to
the Office of the Public Guardian for registration.

## Layout

This crate is a single Loco 0.16 app on axum 0.8 + SeaORM 1.1 +
PostgreSQL + Tera templates with HTMX 2.0.8 and Alpine.js 3.14.8 on the
client.

- `Cargo.toml` — workspace + package manifest.
- `src/` — application code (app boot, controllers, models, views).
- `migration/` — SeaORM migration crate.
- `templates/` — Tera templates per resource (`lpa/`, `person/`, etc.).
- `assets/` — static assets (CSS, JS, images, i18n).
- `config/` — `development.yaml`, `test.yaml`, `production.yaml`.
- `tests/` — integration tests.

See [`AGENTS.md`](AGENTS.md) for backend agent instructions, and the
parent
[`AGENTS/full-stack-with-loco-tera-htmx-alpine.md`](../../../AGENTS/full-stack-with-loco-tera-htmx-alpine.md)
for the canonical full-stack stack.
