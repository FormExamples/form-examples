# CURB-65 — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
CURB-65 clinician wizard; `dashboard.html` is the clinician dashboard. Shared
`css/` and `js/` (the CURB-65 / CRB-65 scoring engine in
`js/{types,rules,grader,flags}.js`, the apps in `js/form-app.js` +
`js/dashboard-app.js`).
