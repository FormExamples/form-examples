# Sports Medicine Assessment — front-end (SvelteKit)

Consolidated SvelteKit front-end (wizard + dashboard) for the Sports Medicine
Assessment (Pre-Participation Physical Evaluation, PPE 5th ed.).

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4 + Lily Design System (Svelte
headless). SVAR DataGrid for the dashboard. Vitest for engine unit tests.

See parent [`../index.md`](../index.md) for the form specification.
