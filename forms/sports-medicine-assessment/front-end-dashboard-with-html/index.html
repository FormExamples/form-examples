The Pre-Participation Physical Evaluation (PPE 5th ed.) is a consensus monograph from AAP / AAFP / ACSM / AMSSM / AOSSM / AOASM used to clear athletes for sport, identify cardiovascular, musculoskeletal, neurological, and Relative Energy Deficiency in Sport (RED-S) risk, and plan follow-up. This dashboard is a clinical-review tool and is not a clearance decision in itself.
