# united-kingdom-nhs-england-medical-exemption-certificate — XML representations

One XML file plus its DTD per SQL table from `../sql/`:

- `patient` — applicant demographics
- `practitioner` — signing practitioner
- `eligible_condition` — closed list of the ten NHSBSA qualifying conditions
- `application` — FP92A application instance
- `application_eligible_condition` — per-application qualifying conditions
- `grade` — eligibility determination
- `grade_fired_rule` — rules that fired during grading
- `grade_additional_flag` — advisory flags raised during grading

Generated by `bin/xml-representations/generate-xml-representations.py`.
