# X-Ray Test Request — front-end with Svelte

SvelteKit single-page wizard for capturing a plain-radiograph (X-ray) request
(referral) and presenting the four-axis vetting grade (appropriateness,
radiation safety, request completeness, triage priority) plus a radiation-dose
band, pregnancy / IR(ME)R safety flags, and the overall vetting recommendation.
A vetting dashboard at `/x-ray-test-requests` lists sample requests.
