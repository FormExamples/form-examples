# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Marker-to-indication appropriateness (NICE / ACB / RCPath)

| Marker | Established appropriate use | Avoid |
| --- | --- | --- |
| PSA | Prostate cancer — symptomatic or informed-choice testing | Asymptomatic population screening |
| CA125 | Suspected ovarian cancer (NICE CG122 / NG12) | Non-specific symptom screening |
| CA19-9 | Pancreatic / hepatobiliary cancer | Screening; benign biliary disease raises it |
| CEA | Colorectal cancer monitoring / recurrence | Screening (smoking raises it) |
| AFP | Hepatocellular carcinoma; germ-cell tumours | General screening |
| beta-hCG | Germ-cell / trophoblastic tumours | — |
| CA15-3 | Breast cancer monitoring | Early-stage screening / diagnosis |
| LDH | Germ-cell tumour staging; lymphoma prognosis | Non-specific (raised in haemolysis, tissue damage) |
| Calcitonin | Medullary thyroid carcinoma | Routine thyroid screening |
| Chromogranin A | Neuroendocrine tumours | Affected by PPIs, renal impairment |

## Appropriateness (1–9 anchored scale)

Ordinal 1–9 in three bands: usually-appropriate (7–9), may-be-appropriate
(4–6), usually-not-appropriate (1–3). There is **no single published 1–9
tumour-marker score**; the scale is anchored on marker-to-indication fit per
NICE and ACB / RCPath guidance and is decision support, not a validated
instrument.

## Interpretation safety

| Band | Triggers |
| --- | --- |
| ok | Marker matches indication; timing and prior context provided |
| caution | On-treatment without baseline, or no previous value for monitoring / response |
| misuse-risk | Tumour markers requested as broad screening in asymptomatic / non-specific presentations |

## Triage tiers

| Tier | Target | Triggers |
| --- | --- | --- |
| Two-week-wait | ≤ 2 weeks | Suspected cancer meeting NICE NG12 referral criteria |
| Urgent | 24–72 h | Symptomatic suspected malignancy needing prompt characterization |
| Routine | standard turnaround | Monitoring, surveillance, treatment-response checks |
