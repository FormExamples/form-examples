# Neurodiversity Adjustment Review — front-end-with-svelte/

SvelteKit single continuous single-page wizard for the UK workplace
reasonable-adjustments review for neurodiversity (ACAS / Equality Act 2010; not
clinical), with the six review sections (review identification, worker
identification, effectiveness, worker experience, changes & next steps, sign-off)
and the four-axis grade (overall effectiveness, wellbeing risk, review
completeness, next-step urgency). Lily Design System Svelte conventions; rule and
flag IDs match the back-end. RESTful routes: `/neurodiversity-adjustment-reviews/`
list + `/neurodiversity-adjustment-reviews/[id]` form. See the form root
[`../AGENTS.md`](../AGENTS.md) and [`../spec/`](../spec).
