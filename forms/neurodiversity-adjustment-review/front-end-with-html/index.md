# Neurodiversity Adjustment Review — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
effectiveness-review wizard; `dashboard.html` is the reviews dashboard. Shared
`css/` and `js/` (the four-axis grading engine in
`js/{types,rules,flags,grader}.js` — effectiveness, wellbeing risk, review
completeness, next-step urgency).
