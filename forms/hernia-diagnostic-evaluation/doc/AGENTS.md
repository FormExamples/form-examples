# Hernia Diagnostic Evaluation — reference material

Free-form documentation directory. Place reference material — classification
source citations, urgency-rule tables, licensing notes, regulatory references
— here as markdown files. The contents are read by humans and agents alike;
keep filenames descriptive (`ehs-classification.md`, `urgency-rules.md`,
etc.).

See [`index.md`](./index.md) for the current file index and the instrument
licensing table.
