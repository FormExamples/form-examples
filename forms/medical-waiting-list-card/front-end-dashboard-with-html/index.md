# Medical Waiting List Card — static HTML dashboard

Static single-page HTML dashboard mirroring the SvelteKit dashboard.
Uses a sortable HTML table and the Lily Design System (HTML headless).

See the form-level [`../AGENTS.md`](../AGENTS.md) for the data model and
[`../../AGENTS-front-end-html.md`](../../AGENTS-front-end-html.md) for the
shared Lily HTML conventions.

The HTML dashboard is offered for sites that cannot run a SvelteKit
build, and as the reference Lily-class contract verified by
`bin/lily-html-refactor --check`.
