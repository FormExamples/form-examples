# Medical Waiting List Card — static HTML dashboard

Static single-page HTML dashboard using a sortable table and the Lily
Design System HTML headless components. See
[`../../AGENTS-front-end-html.md`](../../AGENTS-front-end-html.md) for the
shared Lily HTML conventions. Held to the same Lily-class contract as the
SvelteKit dashboard; drift is detected by
`bin/lily-html-refactor --check --all`.
