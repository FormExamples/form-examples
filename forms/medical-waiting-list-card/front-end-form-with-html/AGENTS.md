# Medical Waiting List Card — static HTML practitioner form

Static single-page HTML wizard using Alpine.js and the Lily Design System
HTML headless components. See [`../../AGENTS-front-end-html.md`](../../AGENTS-front-end-html.md)
for the shared Lily HTML conventions.

The HTML form is held to the same Lily-class contract as the SvelteKit
form; drift is detected by `bin/lily-html-refactor --check --all`.
