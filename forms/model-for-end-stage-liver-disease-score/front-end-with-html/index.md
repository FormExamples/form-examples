# MELD Score — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
MELD (Model for End-Stage Liver Disease) wizard; `dashboard.html` is the
clinician dashboard. Shared `css/` and `js/` (the MELD engine in
`js/{types,rules,grader,flags}.js`, the apps in `js/form-app.js` +
`js/dashboard-app.js`).
