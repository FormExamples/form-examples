# Dyslexia assessment protocol

This document describes the assessment battery selection, administration
order, behavioural observations, and reasonable adjustments to be made
during testing.

## Assessor qualifications

A diagnostic dyslexia assessment must be conducted by:

- A **specialist teacher** holding a current Assessment Practising
  Certificate (APC) issued by a SASC-approved awarding body
  (e.g. PATOSS, BDA, Dyslexia Guild), **or**
- A **registered educational, clinical, or counselling psychologist**
  with relevant specialist experience.

SASC guidance requires reports to include the assessor's name,
qualifications, and APC number.

## Recommended battery domains

SASC requires a "full cognitive and attainment profile". The clinician
should select tests covering:

| Domain                       | Example tests (illustrative)         |
| ---------------------------- | ------------------------------------ |
| Reasoning / cognitive ability | WAIS-IV, WISC-V, WRIT, KBIT-2       |
| Single-word reading          | WIAT-III, TOWRE-2, WRAT-5           |
| Reading fluency              | TOWRE-2 SWE/PDE, GORT-5             |
| Reading comprehension        | WIAT-III, YARC, GORT-5              |
| Spelling                     | WIAT-III, WRAT-5, TWS-5             |
| Written expression           | WIAT-III, OWLS-II                   |
| Phonological awareness       | CTOPP-2, PhAB-2                     |
| Phonological memory          | CTOPP-2                             |
| Rapid naming (RAN/RAS)       | CTOPP-2, RAN/RAS, PhAB-2            |
| Working memory               | WAIS-IV / WISC-V working memory index |
| Processing speed             | WAIS-IV / WISC-V processing speed index |

The clinician chooses an appropriate, age-normed battery and records the
exact test names, editions, and forms used.

## Administration order

The SASC guidance recommends starting with rapport-building and lower-stakes
tasks, sequencing demanding cognitive tasks earlier in the session, and
allowing rest breaks. Suggested order:

1. Background interview (Developmental History, Educational Background).
2. Cognitive reasoning subtests.
3. Phonological processing battery.
4. Working memory and processing speed.
5. Single-word reading and decoding.
6. Reading fluency.
7. Reading comprehension.
8. Spelling.
9. Written expression.
10. Debrief and emotional check-in.

## Behavioural observations during testing

The clinician should record:

- **Engagement and effort** — sustained attention, persistence on
  difficult items.
- **Anxiety signs** — fidgeting, avoidance, verbal reports of stress.
- **Strategies used** — finger-tracking, sub-vocalisation,
  self-correction, guessing.
- **Reading behaviour** — left-right tracking errors, word
  substitutions, hesitations, regressions, omissions.
- **Writing behaviour** — pencil grip, handwriting fluency,
  self-correction, letter reversals, dysfluent letter formation.
- **Fatigue** — observable through the session.

## Reasonable adjustments during the assessment

The clinician adjusts the environment to ensure validity:

- Quiet, well-lit room without distractions.
- Coloured overlays available on request (Irlen / Meares-Irlen syndrome).
- Pencils, paper, and a non-digital clock available.
- Permission to take breaks.
- Reading glasses checked and worn if usually worn.

## Emotional and behavioural impact

Captured in the Emotional & Behavioural Impact step. The assessor should
record:

- Self-esteem and academic self-concept.
- Anxiety related to literacy tasks (test anxiety, reading-aloud
  avoidance).
- Coexisting mental health concerns (depression, anxiety disorder).
- Coexisting neurodevelopmental conditions (ADHD, autism, DCD, DLD).

## Recommendations and support plan

Captured in the Recommendations & Support Plan step. Outputs should
include:

- **Educational adjustments** — extra time, reader, scribe, use of
  technology (text-to-speech, speech-to-text), modified printed
  materials.
- **Workplace adjustments** — Access to Work funding signposting in the
  UK, reasonable adjustments under the Equality Act 2010.
- **Recommended teaching approach** — structured, multi-sensory, cumulative
  phonics-based literacy intervention.
- **Onward referrals** — educational psychologist, speech and language
  therapist, optometrist, occupational therapist, mental health support.
