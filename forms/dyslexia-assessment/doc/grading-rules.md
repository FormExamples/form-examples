# Dyslexia — Grading Rules

This form implements a standardised-score battery for the assessment of
specific learning difficulties in reading, writing, and spelling. The
grading rules below follow the conventions of the British Dyslexia
Association (BDA) and the SpLD Assessment Standards Committee (SASC).

## Standard scores — convention

All sub-tests are reported as **standard scores** with a population
**mean of 100** and a **standard deviation of 15**. This is the convention
used by the Wechsler Individual Achievement Test (WIAT), the Wechsler
Intelligence Scale for Children (WISC), and most UK dyslexia assessment
batteries.

| Standard score | Descriptor                      | Severity classification |
| --------------:| ------------------------------- | ----------------------- |
| ≥ 116          | Above average                   | No dyslexia             |
| 85–115         | Average                         | No dyslexia             |
| 70–84          | Below average                   | Mild dyslexia           |
| 55–69          | Well below average              | Moderate dyslexia       |
| < 55           | Significantly below average     | Severe dyslexia         |

A standard score of 85 corresponds to the 16th centile (one SD below the
mean); 70 corresponds to the 2nd centile (two SDs below the mean).

## Assessed domains

The form captures standard scores in the following domains:

| Domain                       | Captured in step                |
| ---------------------------- | ------------------------------- |
| Single-word reading accuracy | Reading Assessment              |
| Reading comprehension        | Reading Assessment              |
| Reading fluency / rate       | Reading Assessment              |
| Spelling                     | Writing & Spelling Assessment   |
| Written expression           | Writing & Spelling Assessment   |
| Phonological awareness       | Phonological Processing         |
| Phonological memory          | Phonological Processing         |
| Rapid automatised naming (RAN) | Phonological Processing       |
| Working memory               | Working Memory & Processing Speed |
| Processing speed             | Working Memory & Processing Speed |

## Severity classification rules

The overall severity classification is determined by the **lowest
consistent pattern** across the literacy and phonological-processing
domains. A single low score does not establish dyslexia; the diagnostic
pattern requires concordant findings.

- **No dyslexia**: all standard scores within average range
  (85+) AND no consistent pattern of difficulty.
- **Mild dyslexia**: one or more literacy scores in the 70–84 range AND
  evidence of compensatory effort OR mild phonological deficit.
- **Moderate dyslexia**: two or more literacy scores in the 55–69 range
  OR a clearly discrepant cognitive/literacy profile with phonological
  deficit.
- **Severe dyslexia**: literacy scores below 55 OR pervasive impact
  across reading accuracy, fluency, spelling, and phonological
  processing.

## Cognitive profile (optional)

Where a cognitive assessment (e.g. WISC-V, WAIS-IV) is available, the
clinician should compare verbal comprehension and perceptual reasoning
indices against literacy scores. A **significant discrepancy** (typically
≥ 1 SD) between general cognitive ability and literacy attainment supports
a dyslexia diagnosis, but the absence of such a discrepancy does not
exclude it (SASC 2019).

## Recommended output

The grading engine produces:

- Per-domain standard scores.
- Domain descriptors (above average / average / below average / well
  below average / significantly below average).
- Overall severity classification (none / mild / moderate / severe).
- A list of flagged issues including: emotional impact concerns,
  inadequate previous support, and recommendations for reasonable
  adjustments.

## Important limitations

- Diagnosis of dyslexia must be made by a **specialist assessor** holding
  a current Assessment Practising Certificate (APC) from a SASC-approved
  professional body (e.g. PATOSS, BDA, Dyslexia Guild) or a registered
  educational/clinical psychologist.
- This form supports the **recording and presentation** of standardised
  scores; it does not administer the underlying tests. The clinician
  remains responsible for selecting and administering an appropriate test
  battery.
- Severity classification is advisory; the diagnostic report must
  document the test battery used, the test conditions, and the clinical
  reasoning.
- Standard scores are population-norm-based; some tests have separate
  age-band norms that must be applied correctly.
