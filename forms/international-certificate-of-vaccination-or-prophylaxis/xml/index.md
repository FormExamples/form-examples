# International Certificate of Vaccination or Prophylaxis — XML representations

One XML file plus its DTD is generated per SQL table by
`bin/xml-representations/generate-xml-representations.py`.

Files:

- `patient.xml` / `patient.dtd`
- `clinician.xml` / `clinician.dtd`
- `center.xml` / `center.dtd`
- `international_certificate_of_vaccination_or_prophylaxis.xml` /
  `international_certificate_of_vaccination_or_prophylaxis.dtd`
- `international_certificate_of_vaccination_or_prophylaxis_entry.xml` /
  `international_certificate_of_vaccination_or_prophylaxis_entry.dtd`
