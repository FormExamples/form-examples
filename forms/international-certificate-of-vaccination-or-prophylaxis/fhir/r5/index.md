# International Certificate of Vaccination or Prophylaxis — FHIR HL7 R5 JSON

FHIR HL7 R5 JSON resources, one file per SQL table. Generated by
`bin/fhir-r5/generate-fhir-r5-representations.py` from the form's
`../sql/` directory. Do not hand-edit — regenerate instead.

Suggested FHIR R5 resource mapping (for a complete `Bundle` export of one
certificate):

| Resource | Purpose |
| --- | --- |
| `Patient` | the vaccinee |
| `Practitioner` | the supervising clinician |
| `Organization` | the WHO-designated administering centre |
| `Immunization` | one resource per vaccination entry |
| `DocumentReference` | the rendered PDF of the certificate |

See root [`AGENTS/fhir-r5.md`](../../../AGENTS/fhir-r5.md) for the FHIR R5
mapping rules.
