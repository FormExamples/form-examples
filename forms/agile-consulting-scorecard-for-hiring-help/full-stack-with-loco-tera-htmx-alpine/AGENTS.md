# Agile Consulting Scorecard for Hiring Help — full-stack with Loco / Tera / HTMX / Alpine.js

Rust full-stack implementation of the agile-consulting scorecard.
Currently the crate ships a pure scoring engine (Cargo lib + CLI) that
mirrors the TypeScript engine in `front-end-form-with-svelte/src/lib/engine/`.
The full Loco app (axum routes, SeaORM entities, Tera templates, HTMX
partials, Alpine.js sprinkles) is generated by the form's
`full-stack-with-loco-tera-htmx-alpine-setup` shell script.

## Status

- Pure scoring engine + 7 unit tests, all passing under `cargo test`.
- CLI binary `agile-consulting-scorecard-cli` reads a JSON
  `AgileConsultingScorecardAssessment` on stdin and prints a `GradeResult`
  on stdout.
- Loco / SeaORM / axum / Tera / HTMX / Alpine.js wiring is *not yet*
  scaffolded. Run the setup script to generate it.

## Stack

- Rust edition 2024
- Loco 0.16 framework on axum 0.8
- SeaORM 1.1 with PostgreSQL 18
- Tera templates with HTMX 2.0.8 and Alpine.js 3.14.8
- `serde(rename_all = "camelCase")` for front-end interop

## Engine

- `src/scoring/types.rs` — `AgileConsultingScorecardAssessment` input,
  `GradeResult` output, plus enums (`Band`, `Instrument`,
  `ItemAnswerGrade`, `FlagCategory`, `FlagPriority`, `Recommendation`).
- `src/scoring/utils.rs` — `answer_to_points`, `answer_to_grade`,
  `total_to_band`, `band_to_recommendation`.
- `src/scoring/manifesto.rs` — items 1–4.
- `src/scoring/principles.rs` — items 5–16 (principles 1–12).
- `src/scoring/flags.rs` — six readiness flags.
- `src/scoring/grader.rs` — top-level `grade_scorecard(&data)`
  entrypoint with embedded `#[cfg(test)]` unit tests.

## Conventions

- camelCase JSON keys via `serde(rename_all = "camelCase")` for parity
  with the Svelte engine and the SQL-derived FHIR resources.
- The full app uses snake_case in Rust struct fields and SQL column
  names (per monorepo-wide convention).
- See [`AGENTS/full-stack-with-loco-tera-htmx-alpine.md`](../../../AGENTS/full-stack-with-loco-tera-htmx-alpine.md)
  for the full conventions.
