# Agile Consulting Scorecard for Hiring Help — Samples

Golden-file fixtures used to verify engine parity between the
TypeScript engine
(`front-end-with-svelte/src/lib/engine/score-grader.ts`),
the Rust engine
(`back-end-with-loco/src/scoring/grader.rs`),
and the vanilla JavaScript engine
(`front-end-with-html/index.html`, inline `<script>`).

## Files

| File | Purpose |
| --- | --- |
| `sample-assessment.json` | Representative `AgileConsultingScorecardAssessment` for a fictional pharmaceuticals enterprise (Pharos Pharma) — 9 yes / 7 no / 0 unanswered |
| `sample-grade.json` | Expected `GradeResult`: total 9/16, band `medium`, recommendation `do-homework-first`, two readiness flags (`no-customer-contact`, `no-self-organization`) |

## How to regenerate

The grade is generated by the Rust CLI from the assessment JSON:

```sh
cd back-end-with-loco
cargo run --quiet --bin agile-consulting-scorecard-cli \
    < ../samples/sample-assessment.json \
    > ../samples/sample-grade.json
```

## Parity tests

Both engines load `sample-assessment.json` and assert that their
output equals `sample-grade.json` byte-for-byte (modulo
JSON-key ordering):

- TypeScript: `front-end-with-svelte/src/lib/engine/parity.test.ts`
- Rust: `#[test]` in `back-end-with-loco/src/scoring/grader.rs`
  (loaded via `include_str!`)
