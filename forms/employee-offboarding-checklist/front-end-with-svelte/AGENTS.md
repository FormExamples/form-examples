# Employee Offboarding Checklist — consolidated front-end (SvelteKit)

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4. Vitest for unit tests.

Consolidated `front-end-with-svelte/`: single-page offboarding checklist wizard
plus an SVAR DataGrid HR dashboard, on RESTful routes
`/employee-offboarding-checklists/` (list) and
`/employee-offboarding-checklists/[id]` (form).

See parent [`../index.md`](../index.md) for the form specification.
