# Outpatient Outcome Report — HTML front-end (form + dashboard)

Consolidated Lily Design System HTML headless front-end: `index.html` is the single-page 11-step wizard; `dashboard.html` is the OOCG grading dashboard. Shared `css/` and `js/`; the four-domain OOCG engine lives in `js/{types,rules,grader,flags}.js`.
