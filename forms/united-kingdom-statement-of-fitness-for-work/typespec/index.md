# TypeSpec — UK Statement of Fitness for Work

[Microsoft TypeSpec](https://typespec.io) definitions for the fit note.
TypeSpec is a schema-first API definition language that emits OpenAPI,
JSON Schema, and Protocol Buffers from a single source.

## Status

Scaffolded; the TypeSpec generator for the form-examples monorepo is not
yet implemented. The intent is to mirror the SQL migrations and Protocol
Buffers into a single TypeSpec project at `main.tsp` from which OpenAPI
and JSON Schema can be emitted.

See `bin/typespec/` (not yet present) for the planned generator.
