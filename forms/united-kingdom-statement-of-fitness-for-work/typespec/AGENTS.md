# typespec/ — Agent Instructions

[Microsoft TypeSpec](https://typespec.io) definitions for the fit note.

TypeSpec is the long-term unifying schema for this form: OpenAPI, JSON
Schema, and Protocol Buffers will all be emitted from `main.tsp` once the
monorepo generator is wired up. Until then this directory holds only
documentation.

See [`./index.md`](./index.md) for status and intent.
