# doc/ — Agent Instructions

Reference documentation supporting the UK fit-note implementation.

The materials here are written from public policy sources (gov.uk, DWP,
Equality Act 2010, NHS Digital). They document:

- the policy rules the grading engine encodes,
- the SNOMED CT codes relevant to diagnosis capture,
- the Equality Act automatic-disability provisions,
- references to the wider DWP and NHS guidance ecosystem.

These documents are stable references — they should not be regenerated by
tooling. Update them only when policy changes.

See [`./index.md`](./index.md) for the file list.
