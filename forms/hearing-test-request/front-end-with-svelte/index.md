# Hearing Test Request — front-end with Svelte

SvelteKit single continuous single-page wizard for capturing an audiology /
hearing-assessment request and presenting the four-axis vetting grade
(appropriateness, urgency triage, request completeness, clinical priority) plus
the overall vetting recommendation and safety-critical flags. A vetting
dashboard at `/hearing-test-requests` lists sample requests; the form lives at
`/hearing-test-requests/[id]` with the report at `/hearing-test-requests/[id]/report`.
