# Provider Transfer Request — consolidated front-end (SvelteKit)

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4 + SVAR DataGrid. Vitest for unit
tests. Single consolidated front-end: RESTful routes
`/provider-transfer-requests/` (dashboard) and
`/provider-transfer-requests/[id]` (wizard) plus `[id]/report` and
`[id]/report/pdf`.

See parent [`../index.md`](../index.md) for the form specification.
