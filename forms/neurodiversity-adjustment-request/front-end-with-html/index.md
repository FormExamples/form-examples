# Neurodiversity Adjustment Request — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
reasonable-adjustments request wizard; `dashboard.html` is the triage dashboard.
Shared `css/` and `js/` (the four-axis grading engine in
`js/{types,rules,flags,grader}.js` — eligibility, impact / wellbeing,
completeness, priority).
