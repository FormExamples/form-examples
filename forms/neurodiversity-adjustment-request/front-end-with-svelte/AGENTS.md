# Neurodiversity Adjustment Request — front-end-with-svelte/

SvelteKit single continuous single-page wizard for the workplace
reasonable-adjustments request for neurodiversity, with the eight request
sections and the four-axis grade (Equality Act 2010 eligibility, impact /
wellbeing risk, request completeness, handling priority) plus an overall
recommendation and compliance-and-wellbeing flags. Lily Design System Svelte
conventions; rule IDs match the back-end. A handling dashboard at
`/neurodiversity-adjustment-requests` lists sample requests with their computed
priority tier and recommendation, reusing the same engine. See the form root
[`../AGENTS.md`](../AGENTS.md) and [`../spec/`](../spec).
