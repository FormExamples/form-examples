# CT Scan Test Request — front-end with Svelte

SvelteKit single-page wizard for capturing a CT (computed tomography) scan
request (referral) and presenting the four-axis vetting grade (appropriateness
1–9, radiation & contrast safety, request completeness, triage priority) plus the
overall vetting recommendation and safety-critical flags. A vetting dashboard at
`/ct-scan-test-requests` lists sample requests with their computed grades.
