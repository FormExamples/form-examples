# Mammography Test Result — front-end-with-svelte/

SvelteKit single continuous single-page wizard for the mammography result
(report), with the seven report sections and the four-axis interpretation grade
centred on the ACR BI-RADS final assessment category. Lily Design System Svelte
conventions; rule IDs match the back-end. See the form root
[`../AGENTS.md`](../AGENTS.md) and [`../spec/`](../spec).
