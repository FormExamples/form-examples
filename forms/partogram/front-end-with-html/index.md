# Partogram — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
labour-record wizard (a parent labour-record header plus a repeating one-to-many
list of timed intrapartum observations); `dashboard.html` is the clinician
dashboard. Shared `css/` and `js/` (the progress / flag engine in
`js/{types,rules,grader,flags}.js`, the apps in `js/form-app.js` +
`js/dashboard-app.js`).
