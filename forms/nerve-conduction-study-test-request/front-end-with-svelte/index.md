# Nerve Conduction Study Test Request — front-end with Svelte

SvelteKit single continuous single-page wizard for capturing a nerve conduction
study / EMG (electrodiagnostic) request and presenting the four-axis vetting
grade (appropriateness, procedural risk, request completeness, triage priority)
plus the overall vetting recommendation. A vetting dashboard at
`/nerve-conduction-study-test-requests` lists sample requests with their computed
grades.
