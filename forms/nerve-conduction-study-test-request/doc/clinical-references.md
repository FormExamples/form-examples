# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Appropriateness (AANEM / AAN electrodiagnostic practice parameters)

Ordinal 1–9 scale in three bands: usually-appropriate (7–9),
may-be-appropriate (4–6), usually-not-appropriate (1–3). Mapped per
(indication × study type × region).

| Indication | Recommended electrodiagnostic approach |
| --- | --- |
| Carpal tunnel | Median sensory / motor nerve conduction; comparative studies; needle EMG to exclude radiculopathy / polyneuropathy |
| Distal symmetric polyneuropathy | Start with sural + peroneal (consider tibial) nerve conduction; combine clinical signs + electrodiagnostic criteria |
| Radiculopathy | Needle EMG most specific for root level; nerve conduction to exclude mimics |
| Suspected motor neurone disease | Nerve conduction + widespread needle EMG for diffuse denervation; expedite |
| Myasthenia | Repetitive nerve stimulation (decrement) |

## Procedural risk

| Band | Drivers |
| --- | --- |
| High | Needle EMG requested while anticoagulated |
| Moderate | Needle EMG with diabetes/other bleeding risk, or pacemaker / ICD with stimulation near the device |
| Low | Nerve conduction only, no anticoagulation, no cardiac device |

Needle EMG carries a small bleeding risk; nerve conduction stimulation warrants
caution near a pacemaker / ICD generator. Both are recorded so the
neurophysiology team can plan technique and ordering.

## Triage tiers

| Tier | Target | Triggers |
| --- | --- | --- |
| Urgent | days–weeks | suspected motor neurone disease; rapidly progressive weakness |
| Routine | standard booking | carpal tunnel, chronic neuropathy, long-standing symptoms |
