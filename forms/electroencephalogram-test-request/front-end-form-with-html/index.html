Clinician referral wizard for an electroencephalogram (EEG) examination. Record the requesting clinician, the patient, the requested EEG type, the clinical indication and specific question, the seizure / epilepsy context and current antiepileptic therapy, the red flags, and the requested urgency. The engine computes a four-axis grade (appropriateness, urgency, request completeness, and clinical priority) plus a set of safety flags.

This is clinical decision support for the neurophysiology vetting desk. Per NICE NG217 an EEG supports a diagnosis of epilepsy and helps classify seizure type / syndrome, but must not be used to exclude epilepsy or in isolation. The final triage and booking decision remains the responsibility of the vetting clinician.
