# Palliative Assessment — consolidated front-end (SvelteKit)

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4. Vitest for unit tests.

Single-page wizard (`/palliative-assessments/[id]`), SVAR DataGrid dashboard
(`/palliative-assessments`), report (`/palliative-assessments/[id]/report`),
and PDF export. The ESAS-r scoring engine lives in `src/lib/engine/`.

See parent [`../index.md`](../index.md) for the form specification.
