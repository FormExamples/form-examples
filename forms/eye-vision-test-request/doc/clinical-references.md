# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Test types and typical indications (RCOphth / College of Optometrists)

| Test type | Typical indication |
| --- | --- |
| Visual acuity | Reduced vision, baseline assessment |
| Visual fields | Suspected glaucoma, visual-field defect, neurological symptoms |
| Refraction | Reduced vision, childhood squint |
| Fundus examination | Diabetic retinopathy screening, flashes / floaters |
| Optical coherence tomography (OCT) | Suspected glaucoma, macular assessment |
| Fluorescein angiography | Diabetic retinopathy, retinal vascular disease |
| Tonometry | Suspected / known glaucoma |
| Slit-lamp | Red eye, anterior-segment assessment |
| Orthoptic assessment | Childhood squint, diplopia |

## Appropriateness (RCOphth / NICE indication match)

Ordinal 1–9 scale in three bands: usually-appropriate (7–9),
may-be-appropriate (4–6), usually-not-appropriate (1–3). Mapped per
(indication × test type). NICE NG81 supports referral filtering for suspected
chronic open-angle glaucoma so that only people needing further investigation
are referred to hospital eye services.

## Triage tiers (RCOphth acute-eye escalation)

| Tier | Target | Triggers |
| --- | --- | --- |
| Emergency | same day / same hour | sudden visual loss, retinal-detachment symptoms (flashes / floaters / curtain), acute painful red eye, suspected giant cell arteritis (GCA) |
| Urgent | 24–72 h / 1–2 weeks | new visual-field defect, suspected glaucoma with high pressure, red eye with pain |
| Routine | standard booking | refraction, routine glaucoma monitoring, diabetic eye screening, childhood squint |

Any acute ophthalmic symptom of GCA is a true ophthalmic emergency: arteritic
anterior ischaemic optic neuropathy can cause sudden, irreversible vision loss
with high risk of fellow-eye involvement, so urgent corticosteroid treatment is
indicated.

## Diabetic eye screening

People with diabetes are screened for diabetic retinopathy by the NHS Diabetic
Eye Screening Programme. From October 2023, low-risk patients in England with no
retinopathy on their last two routine screens move to a 2-yearly interval;
others remain annual.
