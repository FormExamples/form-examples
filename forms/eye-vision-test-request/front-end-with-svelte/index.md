# Eye Vision Test Request — front-end with Svelte

SvelteKit single continuous single-page wizard for capturing an ophthalmic /
optometric eye examination request and presenting the four-axis vetting grade
(appropriateness, urgency / triage priority, request completeness, clinical
priority) plus the overall vetting recommendation. A vetting dashboard at
`/eye-vision-test-requests` lists sample requests with their computed grades.
