# Neurodiversity Adjustment Response — front-end-with-svelte/

SvelteKit single continuous single-page wizard for the workplace
reasonable-adjustments employer response (ACAS / Equality Act 2010; not
clinical), with the seven response sections and the four-axis grade (outcome
classification, legal / discrimination risk, response completeness, follow-up /
review urgency). Lily Design System Svelte conventions; rule IDs match the
back-end. See the form root [`../AGENTS.md`](../AGENTS.md) and
[`../spec/`](../spec).
