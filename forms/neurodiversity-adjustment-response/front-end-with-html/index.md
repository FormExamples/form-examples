# Neurodiversity Adjustment Response — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
employer confirmation-and-review wizard; `dashboard.html` is the decisions
dashboard. Shared `css/` and `js/` (the four-axis grading engine in
`js/{types,rules,flags,grader}.js` — outcome, legal / discrimination risk,
completeness, follow-up / review urgency).
