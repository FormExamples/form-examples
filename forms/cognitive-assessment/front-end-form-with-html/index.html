This questionnaire administers the Mini-Mental State Examination (MMSE), a 30-point validated cognitive screening tool, along with demographic, referral, and functional-history sections. Each MMSE item is scored 0 (incorrect) or 1 (correct). Answers are saved automatically in your browser as you go.

The Mini-Mental State Examination (MMSE) is a validated 30-point screening tool for cognitive impairment in adults. Results should be interpreted in the context of education, language, and sensory function. This form is for information only and is not a diagnosis.
