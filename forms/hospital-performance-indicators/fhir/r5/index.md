# Hospital Performance Indicators — FHIR R5 representations

Generated FHIR HL7 R5 JSON resources mapping each `hospital_performance_indicator*`
SQL entity to a FHIR resource.

The form is **non-clinical**, so the canonical mapping is to a generic
`QuestionnaireResponse` resource.

This directory is regenerated by:

```sh
bin/fhir-r5/generate-fhir-r5-representations.py
```

Do not hand-edit files in this directory; edit the SQL migration
(`../../sql/`) and re-run the generator.
