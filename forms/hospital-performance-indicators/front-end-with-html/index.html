Record a hospital's periodic Balanced Scorecard (Kaplan & Norton, 1992/1996) against 50 indicators grouped into 4 classic strategic perspectives — Finance (9 indicators), Process (28 indicators), Learning and Growth (8 indicators), and Customer (5 indicators). Record each indicator as a numeric value (the unit — ratio, percentage, currency, day count, rate — is implied by the indicator name), with an optional note.

This is a strategic-performance KPI report, not a diagnostic instrument — there is no clinical grading engine. The tool tallies indicators recorded by perspective. Everything runs client-side; nothing is sent to a server from this static page.
