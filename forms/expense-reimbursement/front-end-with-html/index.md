# Expense Reimbursement — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
expense claim wizard; `dashboard.html` is the claims dashboard. Shared `css/`
and `js/` (the three-axis grading engine in `js/{types,rules,flags,grader}.js` —
policy compliance, completeness, approval tier).
