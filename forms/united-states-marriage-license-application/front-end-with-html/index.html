There is no federal marriage license: each state sets the rules and a county clerk issues the license. Same-sex couples may marry in every state (Obergefell v. Hodges, 2015) and every state recognizes a valid marriage from another (Respect for Marriage Act, 2022). This tool documents and checks the application and is not legal advice; the issuing county clerk or a court decides, and rules change, so confirm the waiting period, fee, and witness rules with the clerk.
