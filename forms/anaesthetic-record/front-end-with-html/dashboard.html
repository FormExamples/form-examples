This dashboard is a clinical-documentation tool and is not a diagnosis. The Anaesthetic Record validates each intra-operative chart for completeness (Complete / Partial / Incomplete) and surfaces safety flags (WHO checklist, allergy conflict, difficult airway, anaphylaxis, unlogged consent, physiological derangement); clinical decisions rest with the anaesthetist.
