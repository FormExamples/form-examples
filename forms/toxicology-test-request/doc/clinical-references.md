# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Requested assays and ordering notes

| Assay | Ordering / interpretation note |
| --- | --- |
| Paracetamol level | Interpretable on the UK treatment nomogram only at **≥ 4 h** post-ingestion; consider serial / staggered sampling |
| Salicylate level | Serial levels in significant or sustained-release ingestion |
| Alcohol level | Blood ethanol; corroborates co-ingestion / GCS |
| Drugs-of-abuse screen | Opiates, benzodiazepines, cocaine, amphetamines, etc. |
| Lithium level | Therapeutic range narrow; toxicity at modest elevation |
| Digoxin level | Therapeutic monitoring and suspected toxicity |
| Antiepileptic drug level | Phenytoin, carbamazepine, valproate, etc. |
| Carboxyhaemoglobin | Carbon-monoxide exposure / smoke inhalation |
| Heavy metals | Lead, mercury, arsenic; usually non-urgent |
| Specific drug level | Named agent; record agent in *suspected agent* |

## Appropriateness (Axis A, 1–9)

Ordinal 1–9 scale in three bands: usually-appropriate (7–9),
may-be-appropriate (4–6), usually-not-appropriate (1–3). **There is no single
published toxicology-ordering appropriateness score**; this axis is anchored on
TOXBASE / NPIS indication-to-assay match and is treated as decision support.

## Timing validity (Axis B)

| Band | Meaning |
| --- | --- |
| ok | Assay interpretable at the stated ingestion time |
| caution | Borderline timing or serial sampling advisable (staggered / sustained-release) |
| invalid | Not interpretable — e.g. paracetamol level < 4 h post-ingestion |

The UK paracetamol nomogram was lowered (MHRA directive) to start at
**100 mg/L (660 µmol/L) at 4 h**; levels before 4 h cannot be plotted.

## Triage tiers (Axis D)

| Tier | Target | Triggers |
| --- | --- | --- |
| stat | within the hour | deliberate overdose, symptomatic patient, suspected significant poisoning |
| urgent | same day | acute exposure needing same-day result |
| routine | standard turnaround | therapeutic-drug-monitoring, occupational / forensic screen |

## Safeguarding

All deliberate self-poisonings must be taken seriously: the patient needs a
psychosocial assessment by a specialist mental-health professional while in
hospital (fires `deliberate-self-harm-safeguarding`).
