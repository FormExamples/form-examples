Clinician referral wizard for a toxicology / poisons / therapeutic-drug-level blood-test request. Record the requesting clinician and patient, the requested assays, the clinical indication and ingestion timing, the specimen status, and the requested urgency. The engine computes a four-axis grade (appropriateness, ingestion-timing validity, request completeness, and triage priority) plus a set of safety-critical flags.

This is clinical decision support for the laboratory / toxicology vetting desk. The 1–9 appropriateness scale is anchored on TOXBASE / NPIS indication-to-assay match and is not a single validated instrument. The final triage and assay decision remains the responsibility of the vetting clinician.

Submit the form to see the vetting report.
