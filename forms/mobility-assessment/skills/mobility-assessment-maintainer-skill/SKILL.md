# Mobility Assessment — Maintainer Skill

Implementation-facing companion to `mobility-assessment-skill` (this form's end-user concepts skill) and to `form-examples-maintainer-skill` (the repo-wide maintainer skill — read that one first for the golden rule, generators, and the full verify-gate catalogue). This skill is the one-form-scoped map.

## Directory layout

`forms/mobility-assessment/` contains:

| Subdirectory | Role |
| --- | --- |
| `sql` | source of truth |
| `xml` | generated |
| `fhir` | generated |
| `protobuf` | generated |
| `openapi` | generated |
| `front-end-with-html` | HTML + Lily (wizard + dashboard) |
| `front-end-with-svelte` | SvelteKit (wizard + dashboard) |
| `back-end-with-loco` | Rust + Loco JSON API |

Generated artefacts (`xml`, `fhir`, `protobuf`, `openapi`, the Loco setup script, `CHANGELOG.md`, `examples/assessment.json`) are never hand-edited — regenerate them instead; see the tool catalogue in [`/AGENTS.md`](../../../../AGENTS.md).

## Scoring system

- **Instrument**: Tinetti Assessment Tool
- **Range**: 0-28
- **Categories**: <19 = High fall risk, 19-24 = Moderate risk, 25-28 = Low risk
- **Engine files**: `types.ts`, `tinetti-grader.ts`, `flagged-issues.ts`, `utils.ts`
- **Test file**: `tinetti-grader.test.ts`

## Verify
