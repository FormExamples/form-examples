# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Appropriateness (ACR Appropriateness Criteria)

Ordinal 1–9 scale in three bands: usually-appropriate (7–9), may-be-appropriate
(4–6), usually-not-appropriate (1–3). Mapped per (indication × body region).
Ratings 7–9 mean benefits outweigh risks; 4–6 are equivocal or evidence is
unclear; 1–3 mean risks outweigh benefits.

## MRI safety (ACR Manual on MR Safety / MHRA)

The static magnetic field is always on. Screen items and their default handling:

| Screen item | Default safety handling |
| --- | --- |
| Cardiac pacemaker / ICD | needs-mri-physics-review; contraindicated unless MR-conditional and reprogrammed |
| Intracranial aneurysm clip | contraindicated unless documented MR-conditional / non-ferromagnetic |
| Metallic foreign body in eye / orbit | contraindicated until cleared by orbital radiography |
| Cochlear implant | conditional — MR-conditional labelling + field-strength check |
| Programmable CSF shunt | conditional — reprogramme / re-check after scan |
| Neurostimulator (DBS / SCS / VNS) | conditional — MR-conditional mode and limits |
| Metal implant / prosthesis | conditional — confirm MR-conditional labelling |
| Insulin pump / external device | conditional — remove or confirm MR-safe |
| Claustrophobia | logistical — sedation or open-bore scanner |
| Weight vs bore / table limit | logistical — confirm scanner capacity |

ACR labelling terms (ASTM): **MR Safe**, **MR Conditional**, **MR Unsafe**.
Access to MR Zone IV is restricted; ferromagnetic objects must be positively
identified before Zone III.

## Gadolinium and renal (NSF) risk (ESUR / RCR)

| eGFR (mL/min/1.73 m²) | Contrast-renal flag | Action |
| --- | --- | --- |
| ≥ 60 | none | proceed if contrast indicated |
| 30–60 | caution | use group II / low-risk agent only when necessary |
| < 30 | contraindicated | avoid gadolinium (NSF risk); discuss alternatives |

A previous moderate–severe gadolinium reaction is flagged independently of
eGFR. Pregnancy with requested gadolinium is flagged for senior review.

## Triage tiers

| Tier | Target | Triggers |
| --- | --- | --- |
| Emergency | same day / hours | acute stroke, cord compression, suspected serious infection/haemorrhage |
| Urgent | 24–72 h / 1–2 weeks | suspected malignancy, new neurological deficit, cancer staging |
| Routine | standard booking | follow-up surveillance, chronic stable symptoms |
