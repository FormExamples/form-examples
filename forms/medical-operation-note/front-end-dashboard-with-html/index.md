# Dashboard — static HTML

Static HTML + vanilla JavaScript dashboard listing recently submitted
surgical operation notes (op notes) with the computed composite operative
risk grade, Clavien–Dindo classification, safety flags, and sign-off
status. Read-only review view for theatre coordinators, clinical
governance leads, and morbidity-and-mortality (M&M) meetings.

Open `index.html` directly or serve with `python3 -m http.server 8080`.
