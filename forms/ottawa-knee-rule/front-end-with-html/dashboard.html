The Ottawa Knee Rule is a validated imaging decision rule (Stiell et al. 1995/1996/1997). This dashboard is a clinical-review tool and is not a diagnosis. A knee X-ray is indicated when any one of the five criteria is present, and is not indicated when all five are absent.
