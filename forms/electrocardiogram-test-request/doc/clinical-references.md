# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## ECG type and indication matching (AHA/ACC)

| ECG type | Window / use | Primary indications |
| --- | --- | --- |
| Resting 12-lead | Immediate, first-line | chest pain, suspected MI/ACS, pre-operative, hypertension, screening, heart failure |
| Exercise stress | Scheduled | suspected stable angina, exercise-induced symptoms |
| Ambulatory Holter 24h | Continuous, daily symptoms | palpitations, suspected arrhythmia |
| Ambulatory 48h | Continuous, every 1–2 days | palpitations, suspected arrhythmia |
| Event recorder | Patient-triggered, infrequent | sporadic palpitations / syncope |

## Appropriateness (AHA/ACC ECG use)

Ordinal 1–9 scale in three bands: usually-appropriate (7–9),
may-be-appropriate (4–6), usually-not-appropriate (1–3). Mapped per
(indication × ECG type). The resting 12-lead ECG is the most commonly used and
first-line laboratory procedure for the diagnosis of heart disease; ambulatory
Holter / event monitoring is appropriate for transient arrhythmia symptoms,
matched to symptom frequency.

## Triage tiers (NICE CG95 / ACS pathway)

| Tier | Target | Triggers |
| --- | --- | --- |
| Emergency | same hour | suspected ACS, active chest pain of suspected cardiac origin, suspected VT |
| Urgent | same day / 24–72 h | syncope red flag, currently symptomatic palpitations, stable suspected arrhythmia |
| Routine | standard booking | pre-operative, hypertension, screening, medication monitoring, follow-up |

For suspected ACS, NICE CG95 directs a resting 12-lead ECG as soon as possible,
with STEMI / NSTEMI pathways driven by ST-segment changes, plus a
high-sensitivity troponin sample on arrival.
