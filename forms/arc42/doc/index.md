# arc42 — Reference Documentation

Reference documentation for the arc42 architecture documentation form:
template background, per-section completeness thresholds, composite maturity
band rules, fired-flag inventory, ADR format, and non-clinical safety
considerations.

## Files

- [`arc42-overview.md`](arc42-overview.md) — arc42 template background; 12
  sections with one-paragraph summaries and canonical AsciiDoc filename pattern.
- [`completeness-rules.md`](completeness-rules.md) — per-section minimum
  thresholds for the `complete` grade (`empty` / `partial` / `complete` scale).
- [`maturity-rules.md`](maturity-rules.md) — composite maturity band drivers
  (Draft / Reviewable / Ready / Mature) and the fired-flag inventory
  (high / medium / low priority).
- [`architectural-decision-records.md`](architectural-decision-records.md) —
  ADR practice for step 9: title, status lifecycle, context, decision,
  consequences.
- [`safety-case-notes.md`](safety-case-notes.md) — non-clinical safety
  considerations; reference to ISO/IEC/IEEE 26514:2022.
