# arc42 — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
12-section arc42 documentation wizard; `dashboard.html` is the architecture
dashboard (RESTful resource `arc42-documents`). Shared `css/` and `js/` (the
documentation-maturity engine in `js/{types,rules,flags,grader}.js`).
