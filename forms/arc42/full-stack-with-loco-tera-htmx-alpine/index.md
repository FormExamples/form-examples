# arc42 — Full-stack (Loco / Tera / HTMX / Alpine)

Rust full-stack implementation using Loco 0.16 (axum 0.8), SeaORM 1.1 with
PostgreSQL, Tera templates, HTMX 2.0.8, and Alpine.js 3.14.8. Serves the
14-step arc42 wizard and the assessment dashboard as server-rendered HTML.

**Status:** deferred — scheduled after the SQL migrations and front-end builds
are complete (Phase 3).
