# arc42 — Dashboard (SvelteKit)

SvelteKit + SVAR DataGrid (`@svar-ui/svelte-grid`) review dashboard listing
arc42 assessments with sortable columns and dropdown filters (maturity level,
system name, review date). Backed by a sample-data fallback for standalone
development.

**Status:** deferred — scheduled as Phase 2 after the SvelteKit form is complete.
