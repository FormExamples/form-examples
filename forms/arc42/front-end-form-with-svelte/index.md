# arc42 — Front-end Form (SvelteKit)

SvelteKit 2.x + Svelte 5 + Tailwind CSS 4 single-page wizard (12 steps)
for the arc42 architecture documentation assessment. Includes the TypeScript
scoring engine (`calculateMaturity()`), PDF export via `pdfmake`, and
Vitest unit tests.

**Status:** scheduled for Phase 2 implementation.
