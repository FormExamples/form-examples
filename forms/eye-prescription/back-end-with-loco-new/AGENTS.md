# Eye Prescription — Loco "new" bootstrap

Generated by `bin/create-form` to hold an *initial* `loco new` invocation
for the eye-prescription form. This directory is **transitional**: it
contains only the very first scaffold command, before any tables exist.

The full bootstrap (with `cargo loco generate scaffold` for every table)
lives in
[`../back-end-with-loco-setup`](../back-end-with-loco-setup),
which supersedes this directory.

## File map

- `00-new.sh` — `loco new --name eye-prescription --db postgres ...`
  (generated by `bin/create-form`).

## When to use

Prefer
[`../back-end-with-loco-setup`](../back-end-with-loco-setup)
— it both bootstraps and scaffolds all 10 tables in one go.
