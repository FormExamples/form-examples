# Agile Checklist — Static HTML Form Plan

## Goal

A static, dependency-free, single-page agile-checklist wizard runnable
under `file://` or any static-file server.

## Build order

1. Author `js/items.js` with the 57 items.
2. Author `js/engine.js` mirroring the Svelte composite grader.
3. Author `index.html` and `js/app.js` to render and bind.
4. Style with `css/style.css` (no Tailwind, no build).
5. Manual smoke test: open the page, complete the wizard, see the
   report.
