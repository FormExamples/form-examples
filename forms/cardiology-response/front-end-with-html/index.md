# Cardiology Response — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
response wizard; `dashboard.html` is the responses dashboard. Shared `css/`
and `js/` (the four-axis interpretation engine in `js/{types,rules,flags,grader}.js`,
the apps in `js/form-app.js` + `js/dashboard-app.js`).
