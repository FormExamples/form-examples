# Cardiology Response — front-end-with-svelte/

SvelteKit single continuous single-page wizard for the cardiology response
(consult reply), with the seven response sections and the four-axis
interpretation grade (response classification, condition severity, response
completeness, follow-up urgency). Lily Design System Svelte conventions; rule IDs
match the back-end. See the form root [`../AGENTS.md`](../AGENTS.md) and
[`../spec/`](../spec).
