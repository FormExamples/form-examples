# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Scan-type gestational-age windows (ISUOG / NICE NG201 / NHS FASP)

| Scan type | Window |
| --- | --- |
| Viability | ~6–10 weeks |
| Dating | 11+2 – 14+1 (CRL to 13+6) |
| Nuchal translucency / combined | 11+0 – 14+0 (CRL 45–84 mm) |
| Anomaly (anatomy) | 18+0 – 20+6 |
| Growth / wellbeing | ~26 weeks onward (serial) |
| Doppler surveillance | ≥ ~20 weeks |
| Cervical length | ~16–24 weeks |
| Placental location follow-up | ~32 and ~36 weeks |

## Appropriateness (ACR Appropriateness Criteria)

Ordinal 1–9 scale in three bands: usually-appropriate (7–9),
may-be-appropriate (4–6), usually-not-appropriate (1–3). Mapped per
(indication × scan type × trimester).

## Triage tiers

| Tier | Target | Triggers |
| --- | --- | --- |
| Emergency | same hour | suspected ruptured ectopic, instability, heavy APH |
| Urgent | same day / 24–72 h | reduced fetal movements, stable bleeding/pain, suspected severe FGR |
| Soon | ~1–2 weeks | interval growth/Doppler surveillance, low-lying placenta follow-up |
| Routine | standard booking | dating, NT/combined, anomaly, routine growth |
