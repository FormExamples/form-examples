# Employee Satisfaction Survey — consolidated front-end (SvelteKit)

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4. Vitest for unit tests.

Consolidated gold front-end: the anonymous survey wizard and the HR dashboard
in one app, with RESTful routes `/employee-satisfaction-surveys/` (dashboard)
and `/employee-satisfaction-surveys/[id]` (wizard).

See parent [`../index.md`](../index.md) for the form specification.
