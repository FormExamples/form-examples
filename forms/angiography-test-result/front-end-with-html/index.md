# Angiography Test Result — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
angiography report-entry wizard (seven sections with a live four-axis
interpretation preview); `dashboard.html` is the clinician dashboard. Shared
`css/` and `js/` (the four-axis grading engine in
`js/{types,rules,grader,flags}.js`, the apps in `js/form-app.js` +
`js/dashboard-app.js`).
