# Knee Replacement Surgery Evaluation — reference material

Free-form documentation directory. Place reference material — instrument
source citations, scoring tables, licensing notes, regulatory references —
here as markdown files. The contents are read by humans and agents alike;
keep filenames descriptive (`oks-scoring.md`, `safety-case-notes.md`, etc.).

See [`index.md`](./index.md) for the current file index and the instrument
licensing table.
