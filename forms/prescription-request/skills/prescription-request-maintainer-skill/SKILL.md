# Prescription Request — Maintainer Skill

Implementation-facing companion to `prescription-request-skill` (this form's end-user concepts skill) and to `form-examples-maintainer-skill` (the repo-wide maintainer skill — read that one first for the golden rule, generators, and the full verify-gate catalogue). This skill is the one-form-scoped map.

## Directory layout

`forms/prescription-request/` contains:

| Subdirectory | Role |
| --- | --- |
| `sql` | source of truth |
| `xml` | generated |
| `fhir` | generated |
| `protobuf` | generated |
| `openapi` | generated |
| `front-end-with-html` | HTML + Lily (wizard + dashboard) |
| `front-end-with-svelte` | SvelteKit (wizard + dashboard) |
| `back-end-with-loco` | Rust + Loco JSON API |

Generated artefacts (`xml`, `fhir`, `protobuf`, `openapi`, the Loco setup script, `CHANGELOG.md`, `examples/assessment.json`) are never hand-edited — regenerate them instead; see the tool catalogue in [`/AGENTS.md`](../../../../AGENTS.md).

## Scoring system

- **Instrument**: Priority Classification
- **Range**: Routine / Urgent / Emergency
- **Engine files**: `types.ts`, `prescription-rules.ts`, `prescription-grader.ts`, `flagged-issues.ts`, `utils.ts`
- **Test file**: `prescription-grader.test.ts`

## Verify

```sh
bin/test-form prescription-request
bin/test-sql-apply prescription-request
bin/test-personas prescription-request
bin/test-e2e --html prescription-request
```
