# Learning Disability Assessment — consolidated front-end (SvelteKit)

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4 (Lily Design System Svelte
headless). Vitest for unit tests. SVAR DataGrid for the clinician dashboard.

Consolidated `front-end-with-svelte/`: RESTful routes
`/learning-disability-assessments/` (dashboard) and
`/learning-disability-assessments/[id]` (wizard) + `[id]/report` +
`[id]/report/pdf`.

See parent [`../index.md`](../index.md) for the form specification.
