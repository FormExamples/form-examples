# Learning Disability Assessment — Maintainer Skill

Implementation-facing companion to `learning-disability-assessment-skill` (this form's end-user concepts skill) and to `form-examples-maintainer-skill` (the repo-wide maintainer skill — read that one first for the golden rule, generators, and the full verify-gate catalogue). This skill is the one-form-scoped map.

## Directory layout

`forms/learning-disability-assessment/` contains:

| Subdirectory | Role |
| --- | --- |
| `sql` | source of truth |
| `xml` | generated |
| `fhir` | generated |
| `protobuf` | generated |
| `openapi` | generated |
| `front-end-with-html` | HTML + Lily (wizard + dashboard) |
| `front-end-with-svelte` | SvelteKit (wizard + dashboard) |
| `back-end-with-loco` | Rust + Loco JSON API |

Generated artefacts (`xml`, `fhir`, `protobuf`, `openapi`, the Loco setup script, `CHANGELOG.md`, `examples/assessment.json`) are never hand-edited — regenerate them instead; see the tool catalogue in [`/AGENTS.md`](../../../../AGENTS.md).

## Scoring system

- **Instrument**: NHS England Annual Health Check + Adaptive Behaviour Scale
- **Range**: Mild / Moderate / Severe / Profound
- **Engine files**: `types.ts`, `ld-grader.ts`, `rules.ts`, `flagged-issues.ts`, `utils.ts`
- **Test file**: `ld-grader.test.ts`

## Verify

```sh
bin/test-form learning-disability-assessment
bin/test-sql-apply learning-disability-assessment
bin/test-personas learning-disability-assessment
bin/test-e2e --html learning-disability-assessment
```
