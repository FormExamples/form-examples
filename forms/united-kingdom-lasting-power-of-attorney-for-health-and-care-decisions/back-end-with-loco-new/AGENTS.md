# UK LPA for Health and Care Decisions — Loco scaffold generator — Agent Instructions

Shell scripts that bootstrap the Loco crate in the sibling
`../back-end-with-loco/` directory.

## Files

- `00-new.sh` — creates Postgres roles, three databases (`*_development`,
  `*_test`, `*_production`), and runs `loco new --name <slug> --db
  postgres --bg async --assets serverside`.

The script is regenerated by `bin/create-form`. Manual edits should be
limited to substituting the form slug if the directory is renamed.

See the parent
[AGENTS/back-end-with-loco-setup.md](../../../AGENTS/back-end-with-loco-setup.md)
for the canonical setup-script conventions.
