# UK LPA for Health and Care Decisions — XML and DTD

Generated XML and DTD artifacts, one pair per SQL table entity. Used for
archival in legacy practice-management systems and for legacy XML-based
court / OPG submissions that pre-date the FHIR channel.

Generated artifacts: do not edit by hand. Regenerate via
`bin/xml-representations/generate-xml-representations.py <form-slug>`.

See root [`AGENTS/xml-representations.md`](../../../AGENTS/xml-representations.md)
for the SQL → XML mapping rules.
