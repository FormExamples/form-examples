# UK LPA for Health and Care Decisions — Loco scaffold generator

Shell scripts that scaffold the Loco crate in the sibling
`../full-stack-with-loco-tera-htmx-alpine/` directory. Run once at the
start of the implementation phase.

## Files

- `00-new.sh` — creates the database roles, creates the development /
  test / production databases, and runs `loco new` to produce the crate
  skeleton.

The script is auto-generated by `bin/create-form` from a template; if it
is missing, regenerate by re-running `bin/create-form
united-kingdom-lasting-power-of-attorney-for-health-and-care-decisions`.

## Running

```sh
./00-new.sh
```

Pre-requisites: PostgreSQL ≥ 15 running on `localhost:5432`,
`loco` CLI installed (`cargo install loco-cli`), and the `postgres`
superuser available.
