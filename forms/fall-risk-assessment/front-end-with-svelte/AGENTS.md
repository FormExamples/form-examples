# Fall Risk Assessment — consolidated front-end (SvelteKit)

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4. Vitest for unit tests.

Consolidated gold front-end: single-page wizard + SVAR dashboard under the
RESTful routes `/fall-risk-assessments` (list) and `/fall-risk-assessments/[id]`
(form). Scores with the six-item Morse Fall Scale (MFS).

See parent [`../index.md`](../index.md) for the form specification.
