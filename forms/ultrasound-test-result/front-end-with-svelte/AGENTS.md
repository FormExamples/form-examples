# Ultrasound Test Result — front-end-with-svelte/

SvelteKit single continuous single-page wizard for the general (non-obstetric)
ultrasound result (report), with the seven report sections and the four-axis
interpretation grade. Lily Design System Svelte conventions; rule IDs match the
back-end. Cloned from the gold template `ct-scan-test-result`. See the form root
[`../AGENTS.md`](../AGENTS.md) and [`../spec/`](../spec).
