# Full-Stack — NEW Scaffold Placeholder (FP92A)

Placeholder directory for the regenerated, **next-generation** scaffold of the
FP92A full-stack crate.

The actual working crate is the sibling
[`../full-stack-with-loco-tera-htmx-alpine/`](../full-stack-with-loco-tera-htmx-alpine/),
which is a minimal **axum + Tera + HTMX + Alpine.js** server.

This `-new` directory will be populated by running the sibling shell script
[`../full-stack-with-loco-tera-htmx-alpine-setup`](../full-stack-with-loco-tera-htmx-alpine-setup)
inside a fresh `cargo loco new` project. Once the scaffold builds and the
engine has been ported across, this directory will be promoted to replace
the original crate.

See [`AGENTS.md`](./AGENTS.md) for the intended workflow.
