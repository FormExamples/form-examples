# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Appropriateness (RCPath cancer datasets / tissue pathways)

The RCPath *Cancer datasets and tissue pathways* standardize reporting and
define the range of acceptable practice for handling pathology specimens. Core
data items are mandated for the Cancer Outcomes and Services Dataset in England.
The appropriateness axis maps each (indication × specimen type) onto an ordinal
1–9 scale in three bands: usually-appropriate (7–9), may-be-appropriate (4–6),
usually-not-appropriate (1–3).

| Indication | Specimen example | Band |
| --- | --- | --- |
| Suspected malignancy | biopsy / excision | usually-appropriate |
| Cancer staging | resection | usually-appropriate |
| Margin assessment | re-excision | usually-appropriate |
| Inflammatory disease | endoscopic biopsy | may-be-appropriate |
| Characterize lesion | skin lesion | may-be-appropriate |
| Transplant monitoring | protocol biopsy | may-be-appropriate |

## Specimen quality (fixative / labelling / integrity)

| Band | Triggers |
| --- | --- |
| reject-risk | no fixative recorded for a non-frozen specimen; missing specimen site / labelling; suspected leaking or mislabelled pot |
| caution | fresh tissue without urgent context; high pot count without detail; fixative "other" without note |
| ok | formalin-fixed, labelled, site recorded, integrity not in doubt |

Frozen sections are submitted fresh by design and must reach the lab
immediately; "fresh" fixative is expected, not a fault, when a frozen section is
requested.

## Urgency triage (NICE NG12 + frozen section)

| Tier | Target | Triggers |
| --- | --- | --- |
| Frozen section (immediate) | intra-operative, same session | urgent frozen section requested |
| Two-week-wait | suspected-cancer pathway turnaround | NICE NG12 2WW suspected-cancer referral |
| Urgent | expedited turnaround | clinician-flagged urgent, stable |
| Routine | standard turnaround | routine diagnostic request |

NICE NG12 *Suspected cancer: recognition and referral* sets the two-week-wait
referral expectations by site of cancer; a 2WW request auto-escalates the tier.
