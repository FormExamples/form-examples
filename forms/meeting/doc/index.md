# Meeting — Documentation

Reference documentation for the meeting form. Collects notes on the
recurrence model (the RFC 5545 RRULE shapes the form supports), the
FHIR Appointment / Encounter mapping used by the clinical MDT export,
the iCalendar round-trip behaviour, and the rules emitted by the
validation engine.

The material here grounds the design choices captured in the top-level
[`index.md`](../index.md) and the conventions enforced by
[`AGENTS.md`](../AGENTS.md). It is human-authored prose, not generated.

See the sibling [`AGENTS.md`](./AGENTS.md) for agent instructions.
