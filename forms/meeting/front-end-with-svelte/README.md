# Meeting — consolidated front-end (SvelteKit)

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4 + Lily Design System Svelte
headless. Vitest for the validation engine.

A single-page ten-step wizard at `/meetings/[id]`, a SVAR DataGrid dashboard at
`/meetings/`, a welcome page, a themed layout, an id-keyed reactive store, the
shared validation engine, and a PDF report endpoint. See parent
[`../index.md`](../index.md) for the full form specification.
