# Meeting — Full-stack (Rust) — New Scaffold

Alternative scaffold of the Rust full-stack for the meeting form. This
directory is the **regeneration target** used to compare a fresh
`cargo loco generate scaffold` run against the canonical implementation
in the sibling
[`../full-stack-with-loco-tera-htmx-alpine/`](../full-stack-with-loco-tera-htmx-alpine/).

The canonical implementation is the one the form ships with. This
new-scaffold copy exists so the project can be re-spun from the
`full-stack-with-loco-tera-htmx-alpine-setup` script and the diff
inspected before promoting any change. Once parity is confirmed, the
canonical directory is updated and this directory is discarded or kept
as a snapshot.

See the sibling [`AGENTS.md`](./AGENTS.md) for agent instructions and
[`plan.md`](./plan.md) for the regeneration workflow.
