# United States HIPAA Authorization Form — front-end (SvelteKit)

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4. Vitest for unit tests.

Consolidated gold front-end: a single-page nine-step HIPAA authorization wizard
and a SVAR DataGrid review dashboard, driven by a pure rule-based validity
engine (45 CFR § 164.508). See [`index.md`](./index.md) and the parent
[`../index.md`](../index.md) for the full specification.
