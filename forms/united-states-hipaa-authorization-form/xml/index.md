# united-states-hipaa-authorization-form — xml-representations

XML + DTD example representations of every SQL table in this form.
Generated by `bin/xml-representations/generate-xml-representations.py`
from `../sql/*.sql`.

One `.xml` example and one `.dtd` schema is emitted per table:

- `patient.{xml,dtd}` — patient identification.
- `hipaa_authorization.{xml,dtd}` — parent entity.
- `signer.{xml,dtd}` — signer identification.
- `disclosing_source.{xml,dtd}` — disclosing source.
- `authorized_recipient.{xml,dtd}` — recipient.
- `records_to_disclose.{xml,dtd}` — PHI description.
- `purpose_of_disclosure.{xml,dtd}` — purpose(s).
- `expiration.{xml,dtd}` — expiration date or event.
- `patient_rights_acknowledgement.{xml,dtd}` — § 164.508(c)(2) statements.
- `signature_witness.{xml,dtd}` — signature, date, witness.
- `validation_result.{xml,dtd}` — engine result.
- `validation_fired_rule.{xml,dtd}` — per-rule output.
- `validation_additional_flag.{xml,dtd}` — priority-graded flags.

## Regenerate

```sh
bin/xml-representations/generate-xml-representations.py
```
