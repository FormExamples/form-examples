# Obstetrics Assessment — consolidated front-end (SvelteKit)

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4. Vitest for unit tests.
SVAR DataGrid dashboard. Single-page wizard + maternity-team dashboard.

RESTful routes: `/obstetrics-assessments/` (dashboard) and
`/obstetrics-assessments/[id]` (wizard) + `[id]/report` + `[id]/report/pdf`.

See parent [`../index.md`](../index.md) for the form specification.
