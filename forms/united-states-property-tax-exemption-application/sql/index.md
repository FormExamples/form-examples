# united-states-property-tax-exemption-application — sql

PostgreSQL migrations for this form (source of truth). See
`AGENTS/sql.md` for conventions.

## Canonical files

- `00_create_extensions.sql` — required extensions (pgcrypto, pg_trgm).
- `01_create_function_set_updated_at.sql` — trigger function used by every `updated_at` column.
- `02_create_table_applicant.sql` — the property owner who applies.
- `03_create_table_assessor.sql` — the county assessing official who receives the application.

## Form-specific tables

- `04_create_table_property_tax_exemption_application.sql` — main application: applicant and property identification, ownership and occupancy on the assessment date, exemptions claimed, income, proof documents, filing, appeal basics and the declaration.
- `05_create_table_property_tax_exemption_application_grade.sql` — eligibility classification: class (likely-eligible/incomplete/likely-ineligible), filing deadline, late flag and qualifying exemptions (1:1 UNIQUE FK CASCADE to the application).
- `06_create_table_property_tax_exemption_application_grade_rule.sql` — audit trail of fired eligibility rules (FK CASCADE to grade).
- `07_create_table_property_tax_exemption_application_grade_flag.sql` — flagged issues with priority and suggested action (FK CASCADE to grade).

## Derived artefacts

`schema.sql` is generated by `bin/sql/generate-sql-combined.py`.
