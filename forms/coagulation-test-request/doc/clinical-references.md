# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Requested tests and typical indications

| Test | Typical indication |
| --- | --- |
| Prothrombin time / INR | Warfarin monitoring; liver disease; DIC; pre-operative screen |
| Activated partial thromboplastin time (APTT) | Heparin (UFH) monitoring; unexplained bleeding; lupus anticoagulant screen |
| Fibrinogen (Clauss) | DIC; major haemorrhage; liver disease; obstetric haemorrhage |
| D-dimer | Suspected DVT / PE with low / unlikely Wells pre-test probability; DIC |
| Thrombophilia screen | Selected unprovoked VTE where the result changes management (BSH 2022) |
| Factor assays | Investigation of a confirmed bleeding disorder (e.g. haemophilia) |
| Anti-Xa assay | LMWH / DOAC level (renal impairment, extremes of weight, pregnancy) |
| Mixing studies | Work-up of an unexplained prolonged PT / APTT (inhibitor vs deficiency) |
| Von Willebrand screen | Suspected von Willebrand disease; mucocutaneous bleeding history |

## Appropriateness (Axis A — anchored 1–9 on indication appropriateness)

There is **no single published 1–9 coagulation-ordering score**. The scale is
anchored on indication appropriateness and BSH retest-interval guidance, in
three bands mirroring the ACR-style ordinal convention: usually-appropriate
(7–9), may-be-appropriate (4–6), usually-not-appropriate (1–3).

Key BSH / NICE anchors:

- **Thrombophilia testing** (BSH 2022): test only where it will change
  management — typically VTE < 40 years, spontaneous or with weak provoking
  factors, with an affected first-degree relative; screen for antiphospholipid
  antibodies after unprovoked VTE. Routine / unselected thrombophilia screens
  are usually-not-appropriate.
- **D-dimer for suspected DVT/PE** (NICE NG158): use a 2-level Wells score
  first. D-dimer is for **low / unlikely** pre-test probability to help rule
  out VTE; ordering D-dimer at high pre-test probability (or to "confirm" VTE)
  is low-appropriateness and fires a caution flag.
- **DOAC interference**: DOACs prolong PT / APTT and elevate D-dimer; anti-Xa
  is the appropriate level assay rather than routine PT / APTT.

## Pre-analytical / specimen safety (Axis B — citrate tube fill / ratio / timing)

Coagulation samples use a 3.2% sodium citrate tube relying on a **9:1
blood-to-anticoagulant ratio**. Under-filled tubes (excess citrate) falsely
prolong PT / APTT and must be rejected (`reject-risk`). Delayed analysis,
visible clot, and haemolysis also degrade the sample (`caution` →
`reject-risk`). Band: ok / caution / reject-risk.

## Triage tiers (Axis D)

| Tier | Target | Triggers |
| --- | --- | --- |
| Stat | same hour | active major bleeding; suspected DIC; major-haemorrhage protocol |
| Urgent | same day / few hours | suspected DVT / PE work-up; peri-procedure reversal |
| Routine | standard turnaround | monitoring, pre-operative screen, elective investigation |

Active bleeding or suspected DIC **auto-escalate** the triage tier to stat
regardless of the requested urgency.
