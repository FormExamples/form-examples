# Diabetes Eye Screening record — Back-end with Rust Axum Loco (JSON API)

Pure JSON API back-end for the Diabetes Eye Screening record form, built with axum + Loco +
SeaORM + PostgreSQL. **No HTML rendering, no Tera templates, no HTMX, no
Alpine.js, no CSS, no Lily Design System.**

@../../../AGENTS/back-end-with-loco.md

## Layout

- [`diabetes_eye_screening/`](diabetes_eye_screening/) — the Loco crate (migrations, `src/models/`,
  `src/controllers/`, `config/`, `tests/`).
- Relational per-table schema mirroring [`../sql/`](../sql/): patients,
  clinicians, the form header, child tables, and the grade /
  grade_rule / grade_flag trio.

## Verify

```sh
cd diabetes_eye_screening && cargo build && cargo test
```
