# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Test types and indications (NICE NG80 / NG115, ARTP)

| Test type | Typical indication |
| --- | --- |
| Spirometry | Suspected COPD, baseline obstruction, breathlessness, monitoring |
| Spirometry with reversibility | Suspected asthma, asthma/COPD differentiation |
| Full lung function | Restrictive disease, complex / unexplained breathlessness |
| Gas transfer (DLCO) | Interstitial lung disease, emphysema, pre-chemotherapy |
| Peak flow | Asthma variability, occupational asthma monitoring |
| FeNO | Suspected asthma (eosinophilic airway inflammation) |

NICE NG80 makes spirometry the first-line investigation for suspected asthma,
with bronchodilator reversibility performed if FEV1/FVC < 70 % and FeNO used in
the diagnostic algorithm. NICE NG115 confirms COPD with a post-bronchodilator
FEV1/FVC < 0.7.

## Appropriateness (1–9)

Ordinal 1–9 scale in three bands: usually-appropriate (7–9), may-be-appropriate
(4–6), usually-not-appropriate (1–3). Mapped per (indication × test type).

## Safety / contraindication (ARTP / ERS-ATS)

Forced expiration during spirometry transiently raises intrathoracic,
intracranial, and intra-abdominal pressure. Relative / absolute
contraindications include:

- **Recent myocardial infarction** or unstable cardiovascular status — forced
  expiration may worsen angina or alter blood pressure.
- **Recent thoracic, abdominal, or eye (e.g. cataract) surgery**, and thoracic /
  abdominal / cerebral aneurysm — risk of pressure-related complications.
- **Active respiratory infection** — result validity and infection control.
- **Suspected active tuberculosis / haemoptysis** — infection control with
  shared equipment; defer or use barrier precautions.

| Band | Meaning |
| --- | --- |
| ok | No screened contraindication |
| caution | Relative contraindication; proceed with precautions / timing |
| contraindicated | Defer test; query referrer or arrange alternative |
