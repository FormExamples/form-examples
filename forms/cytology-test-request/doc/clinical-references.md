# Clinical references

Authoritative guidance underpinning the four-axis grading engine.

## Specimen types and reporting systems (RCPath cytopathology)

| Specimen type | Reporting system / guidance |
| --- | --- |
| Cervical smear | NHS Cervical Screening Programme (HPV primary screen + cytology triage) |
| Urine cytology | The Paris System for Reporting Urinary Cytology |
| Sputum cytology | RCPath tissue pathways for diagnostic cytopathology |
| Fluid — pleural / ascitic | The International System for Reporting Serous Fluid Cytopathology |
| Fine-needle aspiration — thyroid | RCPath thyroid cytology (Thy1–Thy5) |
| Fine-needle aspiration — breast | RCPath / NHSBSP breast cytology |
| CSF cytology | RCPath tissue pathways for diagnostic cytopathology |

## Appropriateness (Axis A)

Ordinal 1–9 scale in three bands: usually-appropriate (7–9),
may-be-appropriate (4–6), usually-not-appropriate (1–3). Mapped per
(indication × specimen type), grounded in the NHS Cervical Screening Programme
pathway for cervical smears and the relevant RCPath specimen guidance for
non-gynaecological cytology.

## Pre-analytical specimen adequacy (Axis B)

| Band | Meaning |
| --- | --- |
| ok | Specimen collected, timing and fixation appropriate to the specimen type |
| caution | Collected but a timing / fixation concern affecting adequacy |
| reject-risk | Not yet collected, or a likely-inadequate / non-diagnostic specimen |

It is imperative that adequate clinical details accompany the specimen so the
reporting cytologist can interpret it in the correct clinical context.

## Triage tiers (Axis D)

| Tier | Target | Triggers |
| --- | --- | --- |
| Two-week-wait | seen within 2 weeks | NICE NG12 suspected-cancer indication; previous high-grade cytology |
| Urgent | a few days | symptomatic effusion / haematuria under active investigation |
| Routine | standard booking | cervical screening; routine surveillance / follow-up |
