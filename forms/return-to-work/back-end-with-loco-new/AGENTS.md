# Return to Work — Loco scaffold generator Agent Instructions

Shell entry-point that bootstraps the sibling Rust full-stack
project via the Loco CLI.

## File map

- `00-new.sh` — generated by `bin/create-form`; creates databases
  and runs `loco new --name return-to-work --db postgres --bg async
  --assets none`.

## Authoring rules

- Keep the script idempotent (`|| :` after `createuser` /
  `createdb`).
- Use `set -euf` for strict failure semantics.
- Match the slug / snake-case naming from the parent
  `forms/<slug>/` directory.
