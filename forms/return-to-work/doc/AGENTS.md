# Return to Work — Documentation Agent Instructions

This directory contains the clinical and regulatory reference material
that grounds the Return to Work form.

## Authoring rules

- Cite the authoritative source for every claim (UK DWP guidance,
  gov.uk publication, HSE, DVLA, Acas, NHS Employers, NICE, SNOMED CT
  release date, etc.).
- Prefer UK NHS terminology and statutes; flag international
  equivalents in a *See also* section when relevant.
- Keep each document focused on one topic; cross-link rather than
  duplicate.
- Do not embed PDFs directly into this repository unless the licence
  permits redistribution; cite the gov.uk URL instead.

## Files

- `index.md` — overview and external sources.
- `med-3-guidance.md` — Med 3 cross-walk.
- `self-certification-sc2.md` — scope boundary with SC2.
- `diagnosis-coding.md` — SNOMED CT / ICD-10 mapping.
- `phased-return-guidance.md` — phased-return template.
- `regulatory-cross-walks.md` — RIDDOR / DVLA / Equality Act.
