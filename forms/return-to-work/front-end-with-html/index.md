# Return to Work — HTML front-end (form + dashboard)

Consolidated single-directory HTML front-end: `index.html` is the single-page
12-step clinician wizard; `dashboard.html` is the clinician review dashboard.
Shared `css/` and `js/` (the pure grading engine in
`js/{types,rules,flags,grader}.js`, ported from the SvelteKit stack).

No build step; open `index.html` directly via `file://`.
