# Medical Information Form for Air Travel — reference material

Reference documentation for the MEDIF form: clinical-source citations, the
IATA recovery windows the engine uses, and a rule-by-rule predicate table.

- [`iata-medical-manual.md`](./iata-medical-manual.md) — alignment with the
  IATA *Medical Manual* and the conservative recovery windows the engine
  uses when carriers diverge.
- [`airline-windows.md`](./airline-windows.md) — comparison table of MEDIF
  recovery windows across major IATA member carriers.
- [`fitness-band-rules.md`](./fitness-band-rules.md) — rule-by-rule predicate
  table for the airline-aligned fitness-to-fly engine.

See `../AGENTS.md` for the agent-facing summary of the same rules.
