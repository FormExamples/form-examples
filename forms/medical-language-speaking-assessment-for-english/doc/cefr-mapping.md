# CEFR mapping

OET is not formally aligned to the CEFR in the same way that IELTS or
Cambridge English exams are. However, the Cambridge Boxhill Language
Assessment Trust publishes an *indicative* CEFR comparison.

- Council of Europe. *Common European Framework of Reference for
  Languages.*
  <https://www.coe.int/en/web/common-european-framework-reference-languages>
- Council of Europe. *CEFR Companion Volume.* 2020.
  <https://www.coe.int/en/web/common-european-framework-reference-languages/the-cefr-companion-volume>

## Indicative mapping

| OET grade | Indicative CEFR |
| --- | --- |
| A | C2 — Proficient (mastery) |
| B | C1 — Proficient (effective operational proficiency) |
| C+ | B2 — Independent (vantage) |
| C | B1 — Independent (threshold) |
| D | A2 — Basic (waystage) |
| E | A1 — Basic (breakthrough) |

Use this mapping for *informational* purposes only — it is not
regulator-endorsed and should not be quoted on registration
documentation as a CEFR statement.

## When CEFR (rather than OET) is the right scale

- *Inter-professional academic transfer* — universities and
  postgraduate programmes typically use CEFR.
- *Pan-European recruitment* — ESCO occupational records use CEFR.
- *Patient-facing materials grading* — readability of patient-
  information leaflets is often expressed at CEFR levels (B1 is the
  NHS England plain-English target).

## Plain English and patient comprehension

The *Information-giving* clinical communication criterion in the OET
Speaking sub-test rewards plain-language explanation. The reference
NHS standard is:

- NHS England. *Content style guide — readability.*
  <https://www.england.nhs.uk/nhsidentity/identity-guidelines/tone-of-voice/>
- NHS digital service manual. *Content design.*
  <https://service-manual.nhs.uk/content>
- Plain English Campaign. *Crystal Mark.*
  <https://www.plainenglish.co.uk/services/crystal-mark.html>

Patient-information leaflets should target the **9- to 11-year-old
reading age** (broadly CEFR B1) per NHS readability guidance.
