# Medical Language Speaking Assessment for English — consolidated front-end (SvelteKit)

SvelteKit 2 + Svelte 5 runes + Tailwind CSS 4 + Lily Design System. Vitest for
unit tests; SVAR DataGrid for the dashboard.

A single continuous wizard captures candidate details, two role-played patient
scenarios, four linguistic criteria (0-6), and five clinical-communication
indicators (0-3). The shared OET grading engine scales the combined band total
to the 0-500 score, derives the letter grade A–E and the registration outcome,
and flags issues for the assessment lead. See parent `../index.md` for the full
specification.
