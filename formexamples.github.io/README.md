# formexamples.com

Static documentation site for the [form-examples](https://github.com/formexamples/form-examples) monorepo. Built with SvelteKit + adapter-static, deployed to GitHub Pages.

## Develop

```sh
pnpm install
pnpm run dev
```

## Build

```sh
pnpm run build
pnpm run preview
```

## Deploy

Push to `main` — `.github/workflows/deploy-formexamples.yml` builds and deploys to GitHub Pages automatically.
